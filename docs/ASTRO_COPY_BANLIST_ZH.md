# ASTRO 文案禁词与替代（精密监测体）

## 目标
- 保持「先证据、后解释、再指令」。
- 避免鸡汤化、宿命化、空洞大师词。

## 一级禁词（禁止出现）
- 命中注定、天选、注定如此、唯一答案
- 开运、逆天改命、宇宙奖励你
- 温柔地、慢慢来就好、你值得被爱（脱离证据时）

## 二级降级词（尽量不用）
- 事情很多、状态很乱、最近不顺、要稳住
- 高能量、低能量、频率很高（无数据锚点）
- 大师级、顶级、神级（自我标榜）

## 必须替代为
- `事情很多` -> 指定宫位语义（2宫=资源/现金流，3宫=沟通/合同...）
- `状态很乱` -> 触发类型（主相位/次要相位/轴点）
- `要稳住` -> 动态指令（变量收敛/复核窗上锁/情绪隔离）

## 语态约束
- 默认第三人称观测或系统口吻。
- Decode 层允许降密度，不允许换成鸡汤人格。
- 每条判断应可回溯到数据标签（来源相位 + orb + 权重）。
