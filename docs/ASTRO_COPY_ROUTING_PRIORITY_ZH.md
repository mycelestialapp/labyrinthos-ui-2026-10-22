# ASTRO 文案路由与优先级协议（v1）

## 1) 输出层级（与 UI 小标题一致）
- L1 核心快照（默认可见）：一句结论 + 一句证据 + 一句指令
- L2 逻辑推演（展开）：结构机制与边界
- L3 原始读数（高级）：参数、权重、表意依据
- L4 执行备忘：可执行条目

## 2) 路由输入
- 盘型：本命 / 合盘 / 行运 / 时刻 / 次限 / 三限 / 日返 / 月返
- 触发：主相位、次要相位、轴点相位
- 宫位载荷：按行星分布统计前两位
- 证据：最紧 orb 的 2-3 条相位

## 3) 优先级（高到低）
1. 盘型锚点（时间尺度）
2. 主相位硬触发（对冲、四分、紧合）
3. 轴点联动（ASC/MC）
4. 宫位载荷（前两宫）
5. 次要相位（仅摘要，不抢主线）

## 4) 冲突裁决
- 若“和谐相”与“硬相”并存：先报硬相风险，再报和谐缓冲。
- 若主触发不足阈值：进入静默模式（无重大触发，维持基线）。
- 若出生时刻置信度不足：降低轴点相关结论权重。

## 5) 静默模式触发条件（建议）
- 主触发计数低 + 无紧 orb（<1°）的硬相位
- 输出模板：
  - 结论：今日无重大触发
  - 证据：主触发低密度（附标签）
  - 指令：维持基线节奏

## 6) 证据标签规范
- 每条关键判断旁标注：
  - `source`: 相位类型
  - `orb`: x.xx°
  - `weight`: H / M / L
- 禁止无证据的“精密词”。
