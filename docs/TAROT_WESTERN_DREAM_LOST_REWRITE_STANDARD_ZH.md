# 占梦境／失物寻找：解读1 整改标准（定稿）

适用范围：`lib/tarot-western-reading/dream-q*`、`lost-q*` 全量逐题整改；预题真源仍是 `lib/tarot-western/dream.ts`、`lost.ts`（含 boost／boost2）。  
目标：贴近预题、能选边、能照做；去掉空话套尾；与页面结构（单牌五段／多牌「此位提示」+「本阵合读」）兼容。

---

## 0. 要不要写标准？

**要。** 两大类全量整改若无统一验收条，必然再次漂成「硬钉／空链／牌面看××」模板。  
本文件即整改真源；改文案前先打开本文件，改完用 §5 自检。

---

## 1. 共用铁律（两课都遵守）

### 1.1 贴预题

- 题干与预题**一字不改**（全角／、标点、用词）。
- **lean 必须直接回答预题问的那一刀**（选边、点名对象、点名地点／人／白天哪件事）。
- 禁止答成「通用牌义」或「跟题无关的人生哲理」。

### 1.2 结构（r 八参数不变）

| 字段 | 职责 | 忌讳 |
|---|---|---|
| lean | 扫一眼能懂的裁定（≥12 字） | 空比喻开场；不点题 |
| verdict | 为什么这样判（牌×题） | 复读 lean；运维黑话 |
| speak | 这张牌对你说 | 鸡汤；与题脱节 |
| soul | 一句内在动机／恐惧 | 骂人本身；空洞「你值得」 |
| doToday | **今晚唯一可执行一步** | 多指令并列；纯态度句 |

正逆共 156；倒吊人；禁英文；斜杠全角／。

### 1.3 禁止套尾（整改必删）

下列短语**不得**再出现在 lean／verdict／speak／soul／doToday 正文末尾（类导语 blurb 里可保留一句总括）：

- `牌面看信号与消化`
- `牌面看找回与放手`
- 以及任何「牌面看××。」机械收尾

类说明仍可用一句总括（见 dream.ts／lost.ts 的 dir blurb），**解读条内不再复读**。

### 1.4 口吻：拆穿，不捧场

- 把美化词翻成人话（坚强→死要面子硬扛；缘分→你在拖等）。
- 骂准**自欺行为**，不骂「你就是废」。
- 健康／急症／失联宠物：留就医／报警／场馆底线，不恐吓替代专业处置。

### 1.5 与牌阵的关系（产品已定）

- 单牌：五段齐全，含【今天就做这一步】。
- 多牌：单牌区用【此位提示】（可同源 doToday）；整阵【本阵合读】用规则拼罪名／判决／执行——**不按阵位另写 156×N**。
- 整改只保证单牌成稿质量；合读质量跟 lean／doToday 走。

## 2. 占梦境专项

**预题在问什么：** 信号接到白天哪一件、是消化还是预兆、反复要注意什么——**不是吉凶签**。

### 2.1 lean 合格样

- 必须点名：**白天哪件事／哪口压力／听不听／告诉不告诉** 等预题切口。
- 选边题必须选边（怀念 vs 有未了；当提示 vs 当噪音；该走 vs 压力演戏）。
- 点名题必须点名（抓不住「××」；怕暴露的是「××」）。

### 2.2 doToday 合格样

- 醒来后 24h 内能做的一步：写下三行、减屏幕、先陪／先作息、咨询占不占一节等。
- 禁止只说「去消化」「相信潜意识」。

### 2.3 梦境忌讳词（正文慎用／少堆）

`硬钉`、`空链`、`空探`、`逼钉`、`灌钉`、`焊进`、`空家看守` 等——若用，**一句里最多一次**，且必须翻译成预题里的人话（白天哪件事）。

### 2.4 验收口令（梦）

> 不看牌名，只看 lean + doToday：能不能回答这道预题？今晚能不能照做？

---

## 3. 失物寻找专项

**预题在问什么：** 先翻哪、值不值得找、问谁、报不报、何时停——**要像找东西，不像谈恋爱**。

### 3.1 lean 合格样

- 必须选边或点名：**先报公司 vs 先改密**；**先问另一半 vs 先问家人**；**今晚还翻 vs 先停**；地点／容器／人。
- 禁止用感情向隐喻硬套（空家、戴冠、庆席）到钥匙／电脑上。

### 3.2 doToday 合格样（须含动作词）

至少能落到一类：`翻／问／报／改密／挂失／停翻／约时间再翻`。  
写出**对象**（哪间房、谁、哪个账号），不要「把三处交给边界」这种假具体。

### 3.3 失物忌讳

- 维纳斯阵不用于失物（产品已禁）。
- 正文不写「感情」「复合」「对方爱不爱」。
- 「牌面看找回与放手」不进条尾。

### 3.4 验收口令（失物）

> 把文案念给正在找东西的人听：他会不会立刻知道下一步摸哪／问谁／停不停？

## 4. 全量整改流程（逐题）

顺序建议：失物 → 占梦（或并行两条线，但标准同一套）。

对每一题 `*-qNN`：

1. 打开预题原文（01 里的 `LOST_QNN`／`DREAM_QNN`）。
2. 六文件全开：MAJOR → PENTS。
3. 按 §1–§3 改 lean／doToday 优先，再顺 verdict／speak／soul。
4. 跑该类 checker（`npx tsx scripts/check-lost.ts`／`check-dream.ts`）。
5. 抽 3 张牌在页面点读：预题命中、无套尾、doToday 能做。
6. 题旁打勾：预题号 + 日期。

批量可先做「去套尾」脚本，但**去尾 ≠ 整改完成**；每题仍须过 §2／§3 验收口令。

## 5. 验收清单（每题打勾）

- [ ] 题干与预题一字不差  
- [ ] lean 直接答预题（选边或点名）  
- [ ] 正文无「牌面看信号与消化／找回与放手」套尾  
- [ ] doToday 单一、可执行、贴场景  
- [ ] 无英文；倒吊人；全角／  
- [ ] 156 齐；checker 通过  
- [ ] 失物无感情向错位隐喻；梦有白天切口  

---

## 6. 本阵合读（展示层，不手写组合）

多牌时规则拼：

1. **【罪名】** ← 现在／心／关系 等位的 lean  
2. **【判决】** ← 未来／结果／灵 等位的 lean  
3. **【执行】** ← 行动／建议／结果等位的 doToday（已去套尾）  

合读是否「像人话」，取决于单牌 lean／doToday 是否已按本标准改完。
