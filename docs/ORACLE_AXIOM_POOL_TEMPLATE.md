# 万象引擎 · 语意池填空模板（5 频率 × 12 主题）

**已定稿全量池：** `lib/axiom-pools.ts`（12×5，每格各 4×4×4 条）。若要增删，直接改该文件。

历史：将填好的条目也可拷贝进 `AXIOM_POOLS`，结构为：

```ts
{
  observed: string[]; // 观测宏观
  core: string[];     // 公理主体
  phase: string[];    // 相位调节（语气随 Mood 偏置）
}
```

引擎拼装规则：`assembleAxiomTriplet` 会为每段自动补 `。` 后硬接三节。**填池时请大声连读**「观测 + 公理 + 相位」，别扭则改池不改引擎。

---

## 全局写作约束

| 要做 | 不要做 |
|------|--------|
| 物理/场域/读数感隐喻 | 建议、加油、努力、生活、鸡汤、洗脸 |
| 冷宣判、零寒暄 | 防小人、登基、唯一（滥用人称大词） |
| 单句可独立成义 | 同一节重复主语（如三连「尔」） |
| 可用占位符 `${LUNAR_PHASE}` `${SOLAR_POSITION}` | 未接月相时引擎会替换为冷备文案 |

**观测层**：像日志头，偏「测到 / 录得 / 界面上发生」。  
**公理核**：该主题在该 mood 下的**一条硬核命题**（可含主题专有隐喻）。  
**相位层**：对该 **Mood** 的语气扰动（收敛、缄默、锚定、显化、弥合）。
