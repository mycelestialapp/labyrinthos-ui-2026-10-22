# 西方解读校对：错别字 + 可英译（定稿备忘）

适用范围：`lib/tarot-western-reading/*` 全类。顺序：顶栏大类从左到右——**感情婚姻 → 事业 → …**。  
**现在只改中文。** 英文版后做；校对时必须让中文语义稳到「可直译」。

## 1. 懂不懂「以后英译」

懂。约束如下：

| 要 | 不要 |
|---|---|
| 一词一义，句子能对译 | 为口吻硬拧到英文对不上的黑话 |
| 选边／动作在中英可对齐 | 中文改判边、英译时偷偷改结论 |
| 隐喻少而可解释 | 「核对写在」「硬解」「一口」堆成病句 |
| 字段仍 lean／verdict／speak／soul／doToday | 中英结构分叉 |

英译是**同义翻译**，不是重写牌义。

## 2. 校对查什么

1. **真错别字**（同音／形近／漏字）  
2. **病句／不通**（读两遍仍不懂）  
3. **不可译压缩**（内部黑话、半截隐喻）  
4. **判边是否仍贴预题**（修通顺时禁止改结论）

## 3. 流程（每一题）

1. 打开 `*-qNN-01.ts` 题干，一字不改。  
2. 六文件通读 lean → doToday 优先。  
3. 只改妨碍理解／错字／不可译处；不借机改口吻大翻案。  
4. 有 checker 的类跑过；抽 2 张牌页面点读。
